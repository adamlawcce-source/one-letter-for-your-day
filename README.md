A tiny Node 22 program for the make.fun bounty
[One Letter for Your Day](https://make.fun/bounty/u-puan-one-letter-for-your-day-e54e9c36).

`main.ts` writes one letter to `/output/entry.txt`: **G** — for "grind", the word
for a day spent grinding through bounty after bounty, entry after entry, no
stopping until the window closes. No network, no randomness, no input — the
same letter on every run.

## Run it

```sh
node main.ts
```
